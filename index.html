DEVOS Starter ZIP 설치 스크립트만 받기
01

Idea Interview

대충 말한 아이디어를 AI가 분석하고, 정말 필요한 결정만 질문합니다.

02

Readiness Gate

필수 요구사항이 비어 있으면 개발 시작을 막아 재작업을 줄입니다.

03

Autonomous Work

Project → Worktree → Agent Session 경계로 여러 기능을 병렬 개발합니다.
